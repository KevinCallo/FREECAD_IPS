Arquitectura de FreeCAD

FreeCAD es una aplicación de modelado 3D paramétrico construida sobre una arquitectura modular que integra múltiples bibliotecas de código abierto.

OpenCASCADE

Núcleo de modelado geométrico. Proporciona las operaciones booleanas, superficies NURBS, y el kernel CAD subyacente.

Coin3D

Biblioteca de visualización 3D basada en Open Inventor. Renderiza la escena y maneja la interacción con el usuario en el viewport.

Qt Framework

Framework de interfaz de usuario. Proporciona ventanas, paneles, menús, y toda la interacción gráfica del entorno de trabajo.

Python

Lenguaje de scripting y extensión. Todos los módulos y workbenches de FreeCAD se escriben en Python sobre la API C++ subyacente.

Módulos del Sistema

FreeCAD organiza su funcionalidad en workbenches (entornos de trabajo). Cada uno agrupa herramientas para una tarea específica de diseño.

BIM

Building Information Modeling. Modelado arquitectónico con elementos como muros, losas, ventanas y estructuras.

Part

Modelado paramétrico de sólidos. Operaciones booleanas, extrusiones, revoluciones y operaciones CSG.

Draft

Dibujo 2D y 3D. Herramientas de croquizado, cotas, capas y anotaciones técnicas.

Arch

Arquitectura. Elementos constructivos, espacios, terrenos, y documentación arquitectónica.

Sketcher

Croquizador 2D. Restricciones geométricas, cotas inteligentes y perfiles para operaciones 3D.

FEM

Análisis de elementos finitos. Mallado, condiciones de borde y simulaciones mecánicas.

Waterfall vs Scrum + DevOps

Comparación entre el enfoque tradicional en cascada que FreeCAD utilizó históricamente y la metodología ágil que aplicamos en este proyecto.

Waterfall (Tradicional)

  • Fases secuenciales sin retorno
  • Entrega única al final del proyecto
  • Cambios tardíos son costosos
  • El cliente ve el producto al final
  • Sin automatización de procesos

Así desarrolló FreeCAD históricamente (2002–2018)

Scrum + DevOps (Nuestro enfoque)

  • Sprints iterativos de 15 días
  • Entregas continuas por sprint
  • Adaptación rápida a cambios del cliente
  • Feedback constante del equipo y stakeholders
  • CI/CD automatizado con GitHub Actions
