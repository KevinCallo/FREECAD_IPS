¿Qué es FreeCAD?

FreeCAD es un modelador 3D paramétrico de propósito general, de código abierto y uso libre, orientado a la ingeniería mecánica, el diseño de productos, la arquitectura y el Building Information Modeling (BIM). Es una herramienta CAD/CAM/CAE con soporte para análisis de elementos finitos (FEM).

Código Abierto

Distribuido bajo licencia LGPL-2.0. Permite uso académico, personal y comercial sin restricciones.

Multiplataforma

Disponible para Windows, macOS y Linux. Interfaz consistente en todos los sistemas operativos.

Paramétrico

Modelado no destructivo mediante árbol de operaciones. Cualquier paso puede editarse en cualquier momento.

Scriptable

Python profundamente integrado. Permite automatizar tareas, crear macros y desarrollar módulos propios.

Historia y Evolución

FreeCAD comenzó en enero de 2001 cuando Jürgen Riegel empezó a trabajar en el proyecto GOM (Modelador Gráfico de Objetos), aprovechando OpenCASCADE — un kernel CAD que acababa de publicarse como código abierto. El 17 de marzo de 2002 registró el software con el nombre FreeCAD. En 2003, Werner Mayer se unió como co-desarrollador; en 2008, Yorik van Havre se incorporó y desarrolló el módulo Draft completamente en Python, demostrando el potencial de extensibilidad de la plataforma.

2001 – 2002

Inicio del proyecto por Jürgen Riegel. Primera versión pública: FreeCAD 0.0.1.

2003 – 2008

Werner Mayer se une. Anuncio público en OpenCASCADE Forum. Yorik van Havre se incorpora.

2009 – 2015

Versiones 0.7 a 0.15. Módulos Draft, PartDesign, Sketcher y FEM introducidos.

2016 – 2023

Adopción de flujo ágil e iterativo. Versiones 0.16 a 0.21 con mejoras en BIM y CAM.

2024 – FreeCAD 1.0

Primera versión estable mayor. Solución al histórico problema de nomenclatura topológica.

2026 – FreeCAD 1.1

Versión más reciente (marzo 2026). Mejoras en rendimiento, módulos y soporte Apple Silicon.

Instalación

FreeCAD puede instalarse en los tres sistemas operativos principales. La forma recomendada es descargar el instalador oficial desde freecad.org/downloads.php. También permite instalar componentes adicionales de terceros a través del Gestor de Complementos integrado.

Windows

Instalador .exe descargable. Compatible con Windows 10 y 11 (64 bits). Instalación guiada sin dependencias externas.

macOS

Archivo .dmg para Mac. Compatible desde macOS 10.12 Sierra. Soporte nativo para Apple Silicon (M1/M2/M3).

Linux

Disponible en repositorios de Ubuntu, Debian, Fedora y Arch. También como AppImage portable sin instalación.

Componentes Adicionales

Gestor de Complementos integrado para instalar workbenches externos y macros de la comunidad con un clic.

Primeros Pasos

Al abrir FreeCAD por primera vez aparece la pantalla de inicio con accesos rápidos a documentos recientes y plantillas. El flujo de trabajo básico consiste en seleccionar un workbench, crear geometría 2D en el Sketcher y aplicar operaciones 3D para obtener sólidos paramétricos.

Seleccionar Workbench

Elegir el entorno de trabajo según la tarea: Part Design para mecánica, BIM para arquitectura.

Crear Sketch

Dibujar geometría 2D en un plano de referencia con restricciones de longitud, ángulo y coincidencia.

Operaciones 3D

Aplicar Pastilla (extrusión), Cajera (corte) o Revolución para generar sólidos paramétricos.

Guardar y Exportar

Guardar en formato .FCStd (nativo) y exportar a STEP, STL, DXF, IFC u otros formatos según necesidad.

Editar Historial

El árbol de modelo permite volver a cualquier operación previa y modificarla sin reconstruir el modelo.

Usar Macros

Automatizar tareas repetitivas con macros Python o grabar acciones directamente desde la interfaz.

Interfaz de Usuario

La interfaz de FreeCAD está construida sobre Qt y se compone de varios elementos gráficos que trabajan de manera integrada. Cada panel cumple una función específica dentro del flujo de trabajo de modelado.

Vista 3D

Área principal de trabajo. Visualización y manipulación del modelo 3D con soporte para vistas ortogonales y perspectiva.

Vista de Árbol

Panel izquierdo con jerarquía del documento: todos los objetos, operaciones y relaciones del modelo.

Editor de Propiedades

Panel inferior izquierdo con las propiedades del objeto seleccionado, editables en tiempo real.

Panel de Tareas

Aparece al activar herramientas. Muestra opciones y parámetros de la operación en curso.

Consola Python

Terminal integrada para ejecutar comandos Python directamente sobre el modelo abierto.

Barra de Herramientas

Accesos rápidos a las herramientas más usadas del workbench activo. Configurable por el usuario.

Navegación y Selección

FreeCAD ofrece múltiples estilos de navegación configurables desde Editar → Preferencias → Pantalla → Navegación 3D. El estilo por defecto usa el botón central del ratón para rotar y la rueda para zoom.

FreeCAD (Default)

Botón central para rotar, Shift + central para desplazar, rueda para zoom.

CAD Navigation

Similar a AutoCAD. Recomendado para usuarios con experiencia en software CAD tradicional.

Gesture

Rotación con clic derecho arrastrado. Ideal para pantallas táctiles y trackpads de laptop.

Selección Simple

Clic en un objeto o cara. Ctrl + clic para selección múltiple en la vista 3D.

Selección por Caja

Arrastrar para seleccionar múltiples objetos dentro de un área rectangular.

Selección en Árbol

Clic en el árbol del modelo para seleccionar y resaltar el objeto en la vista 3D.

Arquitectura de FreeCAD

FreeCAD está construido sobre una arquitectura modular que integra múltiples bibliotecas de código abierto de alto rendimiento. Cada capa puede ser reemplazada o extendida de forma independiente.

OpenCASCADE

Núcleo de modelado geométrico. Operaciones booleanas, superficies NURBS y el kernel CAD subyacente (BREP).

Coin3D

Biblioteca de visualización 3D basada en Open Inventor. Renderiza la escena y maneja la interacción en el viewport.

Qt Framework

Framework de interfaz de usuario. Proporciona ventanas, paneles, menús y toda la interacción gráfica del entorno.

Python

Lenguaje de scripting y extensión. Todos los módulos y workbenches se pueden escribir en Python sobre la API C++.

Módulos del Sistema (Workbenches)

FreeCAD organiza su funcionalidad en workbenches (entornos de trabajo). Cada uno agrupa herramientas para una tarea específica. El usuario cambia de workbench según el tipo de trabajo sin perder el avance realizado.

BIM

Building Information Modeling. Muros, losas, ventanas y estructuras con soporte IFC para interoperabilidad.

Part

Modelado paramétrico de sólidos. Operaciones booleanas, extrusiones, revoluciones y operaciones CSG.

Draft

Dibujo 2D y 3D. Herramientas de croquizado, cotas, capas, snap y anotaciones técnicas.

Arch

Arquitectura. Elementos constructivos, espacios, terrenos y documentación arquitectónica.

Sketcher

Croquizador 2D con restricciones geométricas, cotas inteligentes y perfiles para operaciones 3D.

FEM

Análisis de elementos finitos. Mallado, condiciones de borde y simulaciones mecánicas y térmicas.

TechDraw

Producción de planos técnicos 2D con cotas y anotaciones a partir de modelos 3D.

Spreadsheet

Hoja de cálculo integrada para gestionar datos, parámetros y relaciones del modelo.

CAM (Path)

Manufactura asistida por computadora. Genera G-code para máquinas CNC desde modelos 3D.

Macros

Las macros son fragmentos de código Python que automatizan tareas simples o complejas no disponibles de forma nativa en la interfaz. Pueden ejecutarse manualmente, asignarse a atajos de teclado o integrarse en barras de herramientas personalizadas.

Macros de Usuario

Creadas por el propio usuario para automatizar su flujo de trabajo específico o tareas repetitivas.

Macros de la Comunidad

Más de 200 macros publicadas en el repositorio oficial. Instalables desde el Gestor de Complementos.

Macros Grabadas

FreeCAD puede grabar acciones del usuario y convertirlas automáticamente en código Python reutilizable.

Consola Python

Permite ejecutar scripts directamente sobre el modelo abierto para pruebas rápidas y acceso a la API interna.

Waterfall vs Scrum + DevOps

Comparación entre el enfoque tradicional en cascada que FreeCAD utilizó históricamente y la metodología ágil que aplicamos en este proyecto.

Waterfall (Tradicional)

  • Fases secuenciales sin retorno
  • Entrega única al final del proyecto
  • Cambios tardíos son costosos
  • El cliente ve el producto al final
  • Sin automatización de procesos

Así desarrolló FreeCAD históricamente (2002–2018)

Scrum + DevOps (Nuestro enfoque)

  • Sprints iterativos de 15 días
  • Entregas continuas por sprint
  • Adaptación rápida a cambios del cliente
  • Feedback constante del equipo y stakeholders
  • CI/CD automatizado con GitHub Actions

Preguntas Frecuentes

Respuestas a las dudas más comunes sobre FreeCAD, su uso y sus capacidades.

¿Es realmente gratuito para uso comercial?

Sí. La licencia LGPL-2.0 permite uso en proyectos comerciales sin ninguna obligación adicional.

¿Puedo importar archivos de SolidWorks o Revit?

Sí. FreeCAD importa STEP e IGES de SolidWorks, DXF de AutoCAD e IFC de Revit sin plugins adicionales.

¿Es difícil aprender FreeCAD?

Curva de aprendizaje moderada. La wiki oficial en wiki.freecad.org es muy completa y hay comunidad activa en el foro.

¿En qué lenguaje está programado?

El núcleo en C++ con OpenCASCADE. La interfaz usa Qt. Python está integrado para scripting y módulos.

¿Cuál es la versión más reciente?

FreeCAD 1.1 lanzada en marzo de 2026. La versión 1.0 (2024) fue el primer release estable mayor.

¿Qué tan activa es la comunidad?

Más de 3,000 contribuidores en GitHub, 22,000+ estrellas y un foro oficial muy activo en forum.freecad.org.
