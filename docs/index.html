Introducción al Proyecto

Este proyecto aplica la metodología ágil Scrum integrada con prácticas DevOps sobre FreeCAD, un modelador 3D paramétrico de código abierto con licencia LGPL-2.0, desarrollado desde 2002 por Jürgen Riegel, Werner Mayer y Yorik van Havre.

FreeCAD está construido sobre tres pilares tecnológicos: OpenCASCADE como núcleo de modelado geométrico, Coin3D para la visualización 3D, y Qt como framework de interfaz. Su arquitectura modular permite extender sus capacidades mediante Python, siendo ampliamente usado en ingeniería mecánica, arquitectura y BIM (Building Information Modeling).

El equipo conformado por 5 estudiantes de EPIS-UNSA — trabaja sobre el módulo BIM de FreeCAD, aplicando sprints de 15 días, pipeline CI/CD automatizado con GitHub Actions, y seguimiento del proceso mediante GitHub Projects e Issues.

Waterfall vs Scrum + DevOps

Waterfall (Tradicional)

  • Fases secuenciales sin retorno
  • Entrega única al final del proyecto
  • Cambios costosos y difíciles
  • Cliente ve el producto al final
  • Sin automatización de despliegue

Así desarrolló FreeCAD históricamente (2002–2018)

Scrum + DevOps (Nuestro enfoque)

  • Sprints iterativos de 15 días
  • Entregas continuas por sprint
  • Adaptación rápida a cambios
  • Feedback constante del equipo
  • CI/CD automatizado con GitHub Actions
